Semantic Modeling Architecture & Core Enterprise DAX Measures

The architecture implements an optimized **Star Schema Star Network** with an explicit central transaction table linked to denormalized dimension matrices. Below are the key core measures created to compute real-time cumulative run rates without table scans:

1. Advanced YoY Sales Percentage Shifts:
YoY_Sales_Variance_ % = VAR CurrentPeriodSales = SUM('Fact_Sales'[SalesAmount]) VAR PriorPeriodSales = CALCULATE(SUM('Fact_Sales'[SalesAmount]), SAMEPERIODLASTYEAR('Dim_Calendar'[Date])) RETURN DIVIDE(CurrentPeriodSales - PriorPeriodSales, PriorPeriodSales, 0)
2. Rolling 12-Month Trailing Margins:
Trailing_12M_Net_Profit = CALCULATE( SUM('Fact_Sales'[ProfitAmount]), DATESINPERIOD('Dim_Calendar'[Date], MAX('Dim_Calendar'[Date]), -12, MONTH) )
